A recurrent CNN vision-language-action model

No attention, no positional encoding. The model's memory is a stack of 2-D register grids; every clock tick one small convolutional network reads the current token together with the registers and writes the registers back. The same kernels run at every grid position and every tick, which is what makes it a candidate for a single chip running at 100 Hz or more.

How a tick works

  1. The current token's embedding is normalized and copied to every position of a 7 × 7 grid.
  2. That grid, the image and sound grids, and the five registers are concatenated and mixed by a 1 × 1 convolution.
  3. Eight 3 × 3 convolutions with BatchNorm and ReLU transform the result, and a 1 × 1 convolution projects it to register width.
  4. The registers are written as a cascade: each slow register moves 1/W of the way toward what the slower ones have not yet captured (W = 3200, 800, 200, 50 ticks); the last holds the remainder, so the registers always sum to the new output.
  5. A small tree of convolutions collapses the grid to one vector, and a frozen output layer gives the next token.
