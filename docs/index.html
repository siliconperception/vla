A recurrent CNN vision-language-action model

Most commercial applications for autonomous, agile robots do not require superintelligence. They need conversational common sense, grounded in and modulated by what the device perceives: sound, video, touch. To achieve superhuman hand-eye coordination, they need it at frame rates up to 500 Hz, with low and deterministic latency, so the model can sit inside an embedded control loop, and on a power budget a battery can supply.

That rules out a large model streaming its weights from external DRAM. The goal is a vision-language-action model on a single chip: a CNN is parameter-efficient enough that every weight fits in on-chip SRAM, so there is no external memory, and the weights stay programmable. Leaving out external memory also saves power: there are no DRAM chips to keep refreshed and no high-speed interface driving signals between chips, and reading a weight from on-chip SRAM takes on the order of a hundred times less energy than fetching it from off-chip DRAM. The same small kernels run at every grid position and every tick, so about twenty-five million trained weights drive a state of 4.5 million values: associative memories at every grid position, written by the gated delta rule.

The state also has a fixed size. Every tick does exactly the same work and finishes in the same time, however long the model has been running.

How a tick works

  1. The current token is embedded, normalized and copied to all 81 positions of a 9 × 9 grid, then mixed by a 1 × 1 convolution. Earlier tokens reach the model only through its state.
  2. Seven ConvDelta blocks, in series. Each applies five 3 × 3 convolutions with BatchNorm and ReLU and a 1 × 1 convolution, around a skip.
  3. At every grid position, 1 × 1 convolutions and a short causal convolution over the last 4 ticks give 6 heads of query, key and value; two more give a write strength β and a decay α. Each head forgets over its own fixed time scale, which the input can stretch or shrink up to 4×. Each head's 32 × 32 memory is updated by the gated delta rule, M ← α M (I − β k kᵀ) + β v kᵀ: decay, erase what was stored at key k, write v there. It is read with the query and added back through a 1 × 1 convolution.
  4. A small tree of convolutions collapses the last block's grid to one vector, and a frozen output layer gives the next token, which is fed back as the next input.

In training, the convolutions run on all 256 ticks of a window at once, and the memories are trained over the window by an exact chunked parallel scan. On a chip the model runs one tick at a time, with the same result.

In preparation

VLA against pythia-70m, at matched training tokens

Pythia publishes checkpoints from the start of its training, so a small CNN with a fixed-size state can be compared with a transformer at every point along the way, not only at the end. The plan:

  1. Same documents. Score both models on the same held-out FineWeb-Edu and FineWeb documents, by the same rule (nats per token, and per character, which does not depend on the tokenizer).
  2. Loss against tokens seen. One curve per model: the published VLA weights at each step pushed to Hugging Face, and pythia-70m at its checkpoints from 2 M to 300 B tokens.
  3. Use of context. Loss by position in the document (tokens 0-63, 64-255, 256-1023): how much each model gains from what it has already read.
  4. Grammar and common sense. BLiMP and ComVE minimal pairs at matched tokens.
  5. Cost per token. Weights, state and operations per token, next to the scores.

Pythia was trained on the Pile, not FineWeb-Edu; the comparison will show both models on both. Interim scores for the current weights are on the model card.

Samples

From the prompt in bold, with the published weights (59.2 M tokens of training). Locally fluent in places, repetitive, not yet coherent:

The best way to learn a new language is to change grammar and create a new language which will bring it along the way.
The history of the bicycle began in 1972, when the first generation of wheelcar engine sold home for the first time, which after the first generation of electric cars became an electrical power.

Try it

git clone https://github.com/siliconperception/vla && cd vla
pip install -r requirements.txt
for p in "The colors of the rainbow are" \
         "The best way to learn a new language is" \
         "My grandmother's recipe for apple pie starts with" \
         "When you plant a vegetable garden, the first thing to do is" \
         "The history of the bicycle began in"; do
  python vla.py --pretrained --generate --n 120 --prompt "$p" --device cuda
done

Built on

  • Gated delta rule: Yang, Kautz, Hatamizadeh, Gated Delta Networks: Improving Mamba2 with Delta Rule (2024)
  • Chunked parallel training of the delta rule: Yang et al., Parallelizing Linear Transformers with the Delta Rule over Sequence Length (2024)
  • Delta-rule fast weights: Schlag, Irie, Schmidhuber, Linear Transformers Are Secretly Fast Weight Programmers (2021)
  • Matrix-valued recurrent state: Katharopoulos et al., Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention (2020)
  • Data-dependent decay per head: Dao, Gu, Transformers are SSMs (Mamba-2, 2024)
  • A state at every position of a conv grid: Shi et al., Convolutional LSTM Network (2015)
  • Short causal conv before the memory: Fu et al., Hungry Hungry Hippos (2022); Gu, Dao, Mamba (2023)
  • Residual blocks: He et al., Deep Residual Learning for Image Recognition (2015); batch norm: Ioffe, Szegedy, Batch Normalization (2015); RMS norm: Zhang, Sennrich, Root Mean Square Layer Normalization (2019)
  • Tokenizer, frozen embedding and output layer, reference model: Biderman et al., Pythia (2023)
  • Optimizer: Loshchilov, Hutter, Decoupled Weight Decay Regularization (2017); weight averaging: Polyak, Juditsky, Acceleration of Stochastic Approximation by Averaging (1992); data: Lozhkov et al., FineWeb-Edu (2024); Penedo et al., The FineWeb Datasets (2024)
