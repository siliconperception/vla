Reading:
- Memory is context-keyed. Without the slow pair (64 s + 16 s), long-term memory (200K-500K) about halves (+0.022 -> +0.012 averaged)
  and 5K memory halves; without the fast pair it halves too and short-term is nearly gone. The 64 s register alone changes nothing.
- The generalized (held-out) improvement over these 700K steps lives in the slow-register pathway: +0.012 -> +0.006 -> +0.003 as the
  slow registers are removed, unchanged without the fast ones. Recent learning is largely about using document-level context.
- So the register ladder plausibly shapes what the weights keep: a warm-start ladder change is a real experiment, not a no-op.
Caveats: each age bin is ~2 sigma; fast-register ablation also cripples prediction generally, so "keyed on local context" is partly trivial.
